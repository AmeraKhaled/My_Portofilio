# Amera's Digital Canvas

A modern portfolio website showcasing frontend development skills and projects. Built with React, TypeScript, Vite, and Tailwind CSS, featuring responsive design and smooth animations.

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Fast build tool
- **Tailwind CSS** - Styling
- **Shadcn/ui** - Component library
- **React Router** - Navigation
- **React Hook Form** - Form management
- **Framer Motion** - Animations

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

```bash
npm install
# or
bun install
```

### Development

```bash
npm run dev
# or
bun dev
```

### Build

```bash
npm run build
# or
bun build
```

### Preview

```bash
npm run preview
# or
bun preview
```
